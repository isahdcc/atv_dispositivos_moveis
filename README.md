# 🌎 Constantes do Mundo

Aplicativo desenvolvido em **Flutter** para apresentar constantes importantes da **matemática e da física** de forma simples e interativa.

## 👨‍💻 Informações

* **Aluno:** Isabelli Heringer
* **Disciplina:** Dispositivos Móveis
* **Tecnologia:** Flutter / Dart

## 📱 Sobre o aplicativo

O aplicativo apresenta **12 constantes**, divididas em:

* 📐 Matemática
* ⚛️ Física

O usuário pode:

* 🎲 Sortear uma constante;
* 🔢 Alterar a quantidade de casas decimais;
* 🏷️ Filtrar por categoria;
* 📖 Expandir os cartões para visualizar mais informações.
